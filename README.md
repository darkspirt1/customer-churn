# 🔴 Customer Churn Deep Dive & Action Plan

A complete end-to-end data analytics project that predicts 
customer churn and generates actionable business playbooks.

## 🚀 Live Demo
👉 [https://customer-churn-7kugmsdb6zd9q2jylxs96y.streamlit.app/)

## 📊 Project Overview
A company is losing customers but doesn't know why.
This project solves that with:
- Churn analysis by time, customer type & feature usage
- ML model to predict churn probability
- Root cause analysis per customer segment
- Automated "Churn Playbook" with business actions

## 🛠️ Tools Used
- **Python** — Data processing & ML
- **SQL mindset** — Structured analysis approach
- **Scikit-learn** — Gradient Boosting model
- **Streamlit** — Interactive dashboard
- **Power BI ready** — CSV exports included
